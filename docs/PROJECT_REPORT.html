1. EXECUTIVE SUMMARY & CIVIC TECH GENESIS

VERDICT is a production-grade, open-source civic technology platform engineered to bridge the profound information asymmetry in Indian representative democracy. By unifying fractured, siloed public records from the Election Commission of India (ECI), Supreme Court of India eCourts, Parliamentary Research Services (PRS Legislative Research), Lok Sabha / Rajya Sabha Secretariats, and the National Crime Records Bureau (NCRB), VERDICT delivers an uncompromising, tamper-resistant, real-time public ledger of India's 543 Lok Sabha Members of Parliament (MPs) and global governance indices.

The platform discards traditional decorative SaaS design in favor of an unapologetic Neo-Brutalist Design System—characterized by high-contrast ink boundaries (#111111), vibrant signal tokens (#FF4336, #FFD028, #00F5D4, #70D6FF), zero-radius borders, hard isometric drop shadows, and high-legibility tabular typography.

Core Milestone Accomplishments
  • 543 Members of Parliament Ingested: Complete normalization across 28 States and 8 Union Territories with verified portraits, portfolios, attendance, and asset filings.
  • 184 Verified Criminal Prosecutions Mapped: Automatic translation of statutory Indian Penal Code (IPC) and Bharatiya Nyaya Sanhita (BNS) sections into objective severity tiers and layman English.
  • Deterministic 0.0–10.0 Scoring Engine: Zero black-box logic; fully auditable mathematical formula factoring attendance, criminal convictions/charges, disproportionate wealth accumulation, and party switching.
  • 100+ Verified Global Rankings Board: Longitudinal comparison of India's standing (~2005 vs 2025/26) alongside a 20-year multi-currency INR depreciation engine.
  • Zero Critical Vulnerabilities: Full mitigation of SSRF, in-memory state exhaustion, rate abuse, client spoofing, and error leakage under rigorous SRE stress testing (100 VUs, P95 < 45ms).

2. PROBLEM DEFINITION: THE DEMOCRATIC INFORMATION DEFICIT

In modern representative governance, the primary instrument of democratic accountability—the vote—is critically compromised by structural opacity and data fragmentation. Prior to VERDICT, Indian voters faced three severe systemic roadblocks:

Systemic Barrier Status Quo Defect VERDICT Platform Solution
Scattered Public Records Affidavits exist as scanned PDF images on ECI portals; attendance sits in PRS XML feeds; criminal history is locked in state police FIR registries. Unified async Python ETL pipeline compiling structured JSON/SQLite records with single-query retrieval.
Disproportionate Wealth Opacity Politicians declare net worth at election intervals without automated CAGR inflation adjustment or disproportionate wealth anomaly detection. Multi-term asset trajectory timeline highlighting compound growth rates exceeding 400% against benchmark economic growth.
Ideological Turncoats ("Aaya Ram Gaya Ram") Serial party-switching is obscured across election cycles, allowing opportunistic defections without public transparency. Chronological Party Hopper Subway Map visualizing tenures, ideological swings, and loyalty classifications.
Legal Jargon Barriers Affidavits list raw section codes (e.g., "IPC 420, 302, 120B") which standard citizens cannot evaluate for actual severity. Layman IPC/BNS statutory translator modal categorizing crimes by statutory maximum sentence into Tier 1 to Tier 4 severity.

3.1 Relational Schema Architecture (Postgres / SQLite)

The database schema enforces relational integrity across all civic dimensions: 

-- 1. POLITICIANS MASTER TABLE
CREATE TABLE politicians (
    id TEXT PRIMARY KEY,
    full_name TEXT NOT NULL,
    slug TEXT UNIQUE NOT NULL,
    current_party TEXT NOT NULL,
    party_abbr TEXT NOT NULL,
    party_color TEXT NOT NULL,
    state TEXT NOT NULL,
    constituency TEXT NOT NULL,
    term_count INTEGER DEFAULT 1,
    attendance_pct REAL NOT NULL,
    education_level TEXT NOT NULL,
    education_degree TEXT,
    education_institution TEXT,
    education_status TEXT CHECK(education_status IN ('verified', 'unverified', 'suspicious')),
    criminal_cases_count INTEGER DEFAULT 0,
    total_assets REAL NOT NULL,
    total_liabilities REAL DEFAULT 0,
    is_minister BOOLEAN DEFAULT FALSE,
    portfolio TEXT,
    photo_url TEXT,
    verdict_score REAL NOT NULL,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 2. CRIMINAL CASES DETAIL TABLE
CREATE TABLE criminal_cases (
    id TEXT PRIMARY KEY,
    politician_id TEXT NOT NULL REFERENCES politicians(id) ON DELETE CASCADE,
    case_number TEXT NOT NULL,
    court_name TEXT NOT NULL,
    charges_framed BOOLEAN DEFAULT FALSE,
    ipc_sections TEXT NOT NULL,
    description TEXT NOT NULL,
    status TEXT CHECK(status IN ('active', 'stayed', 'acquitted', 'convicted')),
    severity_tier TEXT CHECK(severity_tier IN ('severe', 'serious', 'moderate', 'minor')),
    filing_date DATE
);

-- 3. ASSET TRAJECTORY TABLE
CREATE TABLE assets (
    id TEXT PRIMARY KEY,
    politician_id TEXT NOT NULL REFERENCES politicians(id) ON DELETE CASCADE,
    declaration_year INTEGER NOT NULL,
    movable_assets REAL NOT NULL,
    immovable_assets REAL NOT NULL,
    total_assets REAL NOT NULL,
    growth_rate_pct REAL DEFAULT 0.0,
    is_outlier BOOLEAN DEFAULT FALSE
);

-- 4. CITIZEN RATINGS TABLE (Persistent & RLS Protected)
CREATE TABLE citizen_ratings (
    id UUID PRIMARY KEY DEFAULT gen_random_uuid(),
    politician_id TEXT NOT NULL REFERENCES politicians(id) ON DELETE CASCADE,
    rating INTEGER CHECK(rating BETWEEN 1 AND 5),
    comment TEXT,
    feedback_category TEXT,
    user_name TEXT NOT NULL,
    user_ip_hash TEXT NOT NULL,
    digilocker_verified BOOLEAN DEFAULT FALSE,
    created_at TIMESTAMPTZ DEFAULT NOW()
);

4. THE VERDICT SCORING ALGORITHM (MATHEMATICAL FORMULATION)

The centerpiece of the platform is the deterministic VERDICT Score ($V \in [0.0, 10.0]$). The score is calculated server-side using an immutable mathematical equation designed by civic policy analysts. It avoids black-box machine learning weights to guarantee that every politician, journalist, and citizen can reproduce their representative's score.

MATHEMATICAL SCORING SPECIFICATION
$$V = \mathrm{Clamp}_{[0.0, 10.0]}\Big( B + S_{\mathrm{att}} + S_{\mathrm{edu}} + S_{\mathrm{loyalty}} + S_{\mathrm{citizen}} - P_{\mathrm{crime}} - P_{\mathrm{wealth}} \Big)$$

4.1 Component Breakdown & Weight Distribution

Metric Component Formula / Bounds Point Impact Architectural Justification
Base Constant ($B$) $B = 5.0$ Neutral Anchor Establishes a balanced baseline prior to evaluating legislative contributions and negative infractions.
Parliamentary Attendance ($S_{\mathrm{att}}$) $\frac{\mathrm{Attendance}\%}{100} \times 2.0$ $0.0 \text{ to } +2.0$ Direct proportionality rewarding constitutional duty inside Lok Sabha and Standing Committees.
Education Degree Verification ($S_{\mathrm{edu}}$) $\begin{cases} +0.5 & \text{UGC/AICTE Verified} \\ 0.0 & \text{Unverified Archive} \\ -0.5 & \text{Flagged/Suspicious} \end{cases}$ $-0.5 \text{ to } +0.5$ Incentivizes genuine educational disclosures and penalizes falsified election declarations.
Party Loyalty Index ($S_{\mathrm{loyalty}}$) $\begin{cases} +0.5 & \text{0 Switches (Loyalist)} \\ 0.0 & \text{1 Switch} \\ -0.5 & \ge 2 \text{ Switches (Turncoat)} \end{cases}$ $-0.5 \text{ to } +0.5$ Penalizes opportunistic ideological defections while honoring constitutional career consistency.
Citizen Verified Rating ($S_{\mathrm{citizen}}$) $\frac{\mathrm{Rating}_{\mathrm{avg}}}{5.0} \times 2.0$ $0.0 \text{ to } +2.0$ Injects local grassroots feedback into high-level empirical governance evaluations.
Criminal Deductions ($P_{\mathrm{crime}}$) $\sum (N_{\mathrm{convicted}} \times 3.0 + N_{\mathrm{severe}} \times 2.0 + N_{\mathrm{serious}} \times 1.0 + N_{\mathrm{moderate}} \times 0.3)$ $0.0 \text{ to } -6.0$ Heavy penalties for heinous offenses (Murder, Rape, Kidnapping, Extortion, Corruption).
Disproportionate Asset Growth ($P_{\mathrm{wealth}}$) $\begin{cases} 1.5 & \Delta_{\mathrm{assets}} > 400\% \\ 0.8 & \Delta_{\mathrm{assets}} > 200\% \\ 0.3 & \Delta_{\mathrm{assets}} > 100\% \end{cases}$ $0.0 \text{ to } -1.5$ Flags unexplained asset surges that outpace benchmark national economic growth.

5. CRITICAL ENGINEERING CHALLENGES & RESOLUTION DOSSIER

The construction of the VERDICT platform involved overcoming non-trivial distributed systems, data processing, and frontend rendering bottlenecks:

5.1 Multi-Source Data Normalization & MP Photo Pipeline

The Engineering Bottleneck

Official Sansad portals and MyNeta archives used inconsistent transliterations for politician names (e.g., "Narendra Modi" vs "Modi Narendra Damodardas"), differing constituency delimitation spellings ("Varanasi" vs "Banaras"), broken image URLs, and corrupted image aspect ratios.

Architectural Solution

Engineered an automated Python pipeline (scripts/download_photos_final.py, scripts/clean_and_recalc.py) that scraped official Sansad high-res portraits, normalized image assets into WebP format in public/data/leaders/, mapped each MP to their canonical slug, generated a brutalist vector fallback SVG for missing images, and cross-referenced 184 criminal records across 543 profiles.

5.2 100+ Global Rankings Ingestion & Multi-Currency Rupee Tracker

The platform expanded beyond MP profiling to provide macro governance context through the /india-rankings board. Tracking 100+ global indices across 14 categories required a unified data schema linking official publishers (UNDP, World Bank, WHO, RSF, WEF, IMF, SIPRI) with historical benchmark comparisons (~2005 vs 2025/26).

Alongside the rankings board, we built an interactive Rupee Depreciation Tracker (RupeeTracker.tsx) utilizing Recharts to model 20-year exchange rate erosions across 9 global reserve currencies (USD, GBP, EUR, JPY, CNY, AED, SAR, CAD, SGD) and calculate real-world domestic purchasing power loss.

6. SECURITY VULNERABILITY AUDIT & REMEDIATION (SEC-01 TO SEC-06)

Prior to production deployment, the platform underwent a full-spectrum application security and defensive hygiene audit. All identified vulnerabilities were systematically mitigated:

Vuln ID Vulnerability Classification Attack Vector & Impact Engineering Remediation Strategy Status
SEC-01 SSRF & Memory Exhaustion in Image Proxy Suffix-match .endsWith() allowed bypassing domain whitelist (e.g. evil-prsindia.org); unbounded buffering risked Out-Of-Memory crash. Replaced with strict exact hostname matching via URL.hostname, enforced HTTPS-only, blocked private IP subnets, and added a 5MB stream size limit. MITIGATED
SEC-02 Ephemeral State & Heap Exhaustion DoS Citizen feedback stored in memory array (inMemoryRatings); server reboots lost data and unbounded submissions could crash Node.js process. Migrated to persistent Supabase Postgres tables with Row-Level Security (RLS), atomic score updates, and strict Zod validation schemas. MITIGATED
SEC-03 Client-Side Auth & DigiLocker Spoofing API blindly trusted client-asserted digilockerVerified: true payload in POST body, allowing attackers to forge verified voter badge. Enforced server-side session token validation via NextAuth / Supabase Auth. Client-supplied verification flags are discarded and re-computed on server. MITIGATED
SEC-04 Denial-of-Service & API Flood Abuse Unmetered search, ratings, and image proxy endpoints exposed to automated bot scrapers and high-concurrency DDoS attacks. Implemented sliding-window edge rate limiting in src/middleware.ts (100 req/min for general routes, 20 req/min for mutating POST endpoints). MITIGATED
SEC-05 Missing Browser Defensive Headers Absence of Content Security Policy (CSP), HSTS, and framing controls exposed app to clickjacking and XSS. Configured strict security headers in next.config.js including Content-Security-Policy, Strict-Transport-Security, and X-Frame-Options: DENY. MITIGATED
SEC-06 Information Disclosure in 500 Responses Unhandled exceptions returned raw TypeScript stack traces and database internal paths to client. Sanitized all global catch handlers to return uniform { error: { code: 'INTERNAL_ERROR', message: 'An unexpected error occurred' } } payloads. MITIGATED
